# Chi & Wylie (2014) — The ICAP Framework

**Full citation:** Chi, M. T. H., & Wylie, R. (2014). The ICAP framework: Linking cognitive engagement to active learning outcomes. *Educational Psychologist*, 49(4), 219–243. https://doi.org/10.1080/00461520.2014.965823

**Reference ID in background.html:** `ref-chi-wylie-2014`; cited in §7 (Explaining to others as evidence of Understand).

**Where it lives:**
- Local copy: `docs/references/_pdfs/chi-2014-icap-framework.pdf` (26 pp.; PDF p. 1 is the publisher cover, so printed page = PDF page + 217).

**Accessibility:** Full text held.

**What the background doc claims it says:** Constructive outputs contain new ideas beyond the information given; a verbatim self-explanation is only active (p. 222); notes in one's own words are "often constructive because the summary may include conclusions and inferences" (p. 230), so rewording is a boundary case. An activity's intended mode differs from the enacted one; outputs must be evaluated, and the mode often can only be classified after evaluation (p. 238).

**What it actually says (synthesis):** Proposes four modes of engagement, Interactive > Constructive > Active > Passive, defined by learners' overt behavior and outputs, with lab and classroom evidence (note taking, concept mapping, self-explaining). Section "Using ICAP to evaluate students' outputs" (p. 238) says ICAP can be used to design a rubric to code students' outputs. Used here only for the constructive/active line and the intended-vs-enacted distinction.

**Verdict:** Consistent.
