# Reference-card audit, 2026-10-07

Updates `docs/references/*.md` with the verified findings of two citation audits (both owner-approved and published 2026-10-07): the Measurement Hypotheses audit (`citation-audit-measurement-hypotheses-deep-dive-2026-10-07.md` + `rewrite-changelog.md`) and the Background audit (`citation-audit-background-2026-10-07.md` + `correction-changelog.md`). Both underlying docs (`docs/measurement-hypotheses-deep-dive.html`, `docs/background.html`) were already corrected and merged to `main` before this pass; this pass brings the reference cards into line with those corrected docs and with the audits' own verified quotes, and backfills cards for sources the audits relied on that had none.

PDFs were not edited — only the Markdown cards. All work in this branch (`docs/reference-cards-audit`) was confined to `docs/references/` plus this summary file. `~/projects/ai_career_impact` was read-only throughout (several of its cards were read to check for the same errors, never edited).
