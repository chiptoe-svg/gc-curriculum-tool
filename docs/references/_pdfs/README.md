# Archived source PDFs — not in this repository

The PDFs cited by the audit cards in `docs/references/` are **published works** and are kept
**off this public GitHub repository** (owner decision, 2026-10-05). The files are git-ignored.

Where they are:
- **On the department Mac:** this folder, in the main checkout.
- **Nightly backup:** `reference-pdfs.tar.gz` in every full backup (`scripts/backup/full-backup.sh`);
  `restore.sh` puts them back here.
- **Private library:** 24 of 27 are also in the private `chiptoe-svg/ai_career_impact` repo
  (`library/pdfs/`).

Each card's "Local copy" line names the file. To read a source, ask the maintainer or use the
citation and link in the card. Never commit a PDF here; the `.gitignore` rule
`/docs/references/_pdfs/*.pdf` is what keeps them out.
